# Onegin user manual

В данном проекте реализована модель виртуального процессора с собственным ассемблером.
```
- Язык ассемблера (компилятор) считывает данные из текстового файла и переводит их в неравномерный бинарный код.
- Виртуальная машина считывает бинарный файл и выполняет инструкции из него.
```

Проект создан в рамках образовательного семестрового курса МФТИ ФРКТ,
под руководством [Ильи Рудольфовича Дединского](https://ded32.net.ru/).

Проект создан на операционной системе MacOS. На иных платформах возможна некорректная работа.


## Установка и запуск:
0) Для систем отличных от mac os следует самостоятельно скомпилировать файл "main.cpp".
  
1) Скачайте архив с проектом, распакуйте в произвольную директорию.
2) Если у вас не установлен компилятор языка С++ -- g++, установите его.
3) Запустите файл "asm.sh".
4) Запустите файл "vm.sh".
5) Запустите файл "asm" *"text_input_filename.asm"* *"text_output_filename.bin"*.
6) Запустите файл "vm" *"text_input_filename.asm"*.
5) Если не указать файлы при запуске, программа по умолчанию будет читать данные из файла "code.bin"
6) Готово!


## Описание функционала:

### Реализация компилятора языка ассемблера:
-> asm.cpp

**Поддерживаемые команды:**
| Command name | Description |
| ------------ | ----------- |
| PUSH const | Записывает константное число в стек процессора |
| PUSH [const] | Записывает число из указанной ячейки оперативной памяти в стек процессора |
| PUSH [reg_name + const] | Записывает число из указанной в регистре ячейки оперативной памяти в стек процессора (параметр const не обязателен) |
| PUSH reg_name | Записывает число из указанного регистра процессора в стек процессора |
| POP | Удаляет один элемент из стека |
| POP  [const] | Записывает в указанную ячейку оперативной памяти последний элемент стека процессора |
| POP  [reg_name + const] | Записывает в указанную в регистре ячейку оперативной памяти последний элемент стека процессора (параметр const не обязателен) |
| POP reg_name | Записывает в указанный регистр последний элемент стека процессора |
| JMP :name | Переходит к инструкции следующей за меткой :name |
| JMP instruction_index | Переходит к инструкции по указанному индексу |
| JB | JMP, если предпоследний элемент стека <  последнего элемента стека |
| JBE | JMP, если предпоследний элемент стека <= последнего элемента стека |
| JE | JMP, если предпоследний элемент стека == последнему элементу стека |
| JNE | JMP, если предпоследний элемент стека != последнему элементу стека |
| JAE | JMP, если предпоследний элемент стека >   последнего элемента стека |
| JA | JMP, если предпоследний элемент стека >= последнего элемента стека |
| ADD | Складывает последние два элемента стека, результат возвращает в стек |
| SUB | Вычитает из предпоследнего элемента стека последний элемент стека |
| MUL | Умножает два последних элемента стека |
| DIV | Делит предпоследний элемент стека на последний элемент стека |
| OUT | Выводит в терминал последний элемент стека |
| HLT | Завершает работу программы |
| IN | Записывает число из stdin в стек |
| CALL | Вызывает JMP, запоминая адрес возврата |
| RET | Переходит по последнему адресу возврата |
| SQRT | Вычисляет квадратный корень из последнего элемента стека |
| DISP | Выводит оперативную память в терминал (параметры вывода задаются в vm.h "SC_WEIGHT" "SC_HEIGHT") |

### Реализация собственных компараторов:
-> main.cpp

В файле содержатся компараторы, реализованные для выполнения задания и созданные в процессе написания функции сортировки для проверки ее работоспособности.
  В задании используются:
  1) **CompareStrUp**   - сортировка строк в алфавитном порядке.
  2) **CompareStrDown** - сортировка строк в алфавитном порядке начиная с конца строки.
  3) Вывод оригинального текста.
  
  *Все сортировки не учитывают не буквенные символы и не различают заглавных и строчных символов. Для них все гендеры равны.*

###  Реализация функций вывода:
-> main.cpp
- Функция **PrintStrPointersToFile** выводит в указанный файл текст, содержащийся в структуре File.StrPointers в формате "Номер строки в прочитанном файле -> порядковый номер выводимой строки: содержимое строки".
- Функция **PrintStrArrayToFile** получает массив указателей на строки и выводит его содержимое в формате "Номер строки: содержимое строки".

```
!!! В программе стоит ограничение на длину строки. Изменить ее можно в файле onegin.sh "MAX_STR_LENGTH". 
По умолчанию MAX_STR_LENGTH = 100. При превышении длинны строки могут возникать ошибки. В первую очередь, при возникновении ошибок,
следует увеличить этот параметр.
```
